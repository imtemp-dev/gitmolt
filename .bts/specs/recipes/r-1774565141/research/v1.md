# Research: GitMolt MCP Server

## Current State
- No existing GitMolt code; this is greenfield
- Two MCP server examples in workspace: claude-peers-mcp (1,209 lines) and claude-mem (800+ lines)
- MCP SDK v1.27.1 is latest; uses stdio transport, JSON-RPC protocol
- GitHub App auth via @octokit/auth-app handles JWT + installation token lifecycle automatically

## Key Components

### MCP SDK Patterns (from workspace examples)
- `Server` class with `StdioServerTransport`
- Tool definitions: `{ name, description, inputSchema }` with JSON Schema
- Handler: `setRequestHandler(CallToolRequestSchema, async (req) => ...)`
- Response: `{ content: [{ type: 'text', text: '...' }], isError: boolean }`
- stdout reserved for JSON-RPC; all logging to stderr

### GitHub App Auth Flow
1. Create `Octokit` with `createAppAuth` strategy
2. Provide appId, privateKey, installationId via env vars
3. SDK handles JWT generation, installation token caching/refresh
4. Installation tokens expire after 1 hour (auto-refreshed)

### GitHub API Key Operations
- **Search issues**: `octokit.rest.search.issuesAndPullRequests({ q: 'label:"ai-welcome" is:open repo:...' })`
- **Post comment**: `octokit.rest.issues.createComment({ owner, repo, issue_number, body })`
- **Add label**: `octokit.rest.issues.addLabels({ owner, repo, issue_number, labels })`
- **Create branch**: `octokit.rest.git.createRef({ owner, repo, ref, sha })`
- **Commit file**: `octokit.rest.repos.createOrUpdateFileContents({ owner, repo, path, message, content, branch })`
- **Create draft PR**: `octokit.rest.pulls.create({ owner, repo, title, body, head, base, draft: true })`
- **Check PR status**: `octokit.rest.pulls.get({ owner, repo, pull_number })`

### Required GitHub App Permissions
| Operation | Permission |
|-----------|-----------|
| Read issues | issues: read |
| Post comments, add labels | issues: write |
| Create branches, commit, push | contents: write |
| Create PRs | pull_requests: write |
| Read CI status | checks: read |
| Repo metadata | metadata: read (always granted) |

## Dependencies
- `@modelcontextprotocol/sdk@^1.27.1` — MCP protocol
- `@octokit/rest@^21.0.0` — GitHub REST API
- `@octokit/auth-app@^7.0.0` — GitHub App auth
- `typescript@^5.3.0`, `vitest@^1.0.0`, `tsx@^4.0.0`

## Constraints
- GitHub Search API: max 1000 results, 10 pages
- GitHub API rate limit: 5000 req/hr per installation
- Search API counts as 10 requests per query
- MCP stdout reserved for protocol; stderr for logging
- No way to detect Claude Code session's remaining tokens from MCP

## Patterns (from workspace conventions)
1. Logging to stderr only
2. Non-blocking async initialization
3. Graceful shutdown on SIGTERM/SIGINT
4. Error messages via tool response content, not exceptions
5. Environment variable prefix: `GITMOLT_*`
6. Co-authored-by trailers in commits
7. Label prefixes: `effort:`, `ai-`

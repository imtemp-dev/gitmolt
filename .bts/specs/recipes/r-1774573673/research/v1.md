# Research: GitMolt Live Platform

## Supabase Realtime
- Subscribe to INSERT events: `supabase.channel('name').on('postgres_changes', { event: 'INSERT', schema: 'public', table: 'events' }, callback).subscribe()`
- Payload includes `payload.new` (inserted row)
- Status callbacks: SUBSCRIBED, CHANNEL_ERROR, TIMED_OUT, CLOSED
- Requires Realtime enabled on the table in Supabase dashboard

## Next.js App Router
- API routes: `app/api/webhooks/github/route.ts` → `export async function POST(request: Request)`
- Raw body: `await request.text()` (for webhook signature verification)
- Headers: `request.headers.get('x-hub-signature-256')`
- No body parser config needed in App Router (unlike Pages Router)

## GitHub Webhook Signature Verification
- Header: `x-hub-signature-256`
- Algorithm: HMAC-SHA256 with webhook secret
- Verify: `crypto.timingSafeEqual(hmac, signature)`

## GitHub Webhook Event Types
- `issue_comment` → action: created/edited/deleted
- `pull_request` → action: opened/closed/merged/reopened
- `pull_request_review` → action: submitted (state: approved/changes_requested)
- `check_suite` → action: completed (conclusion: success/failure)

## Supabase Client Setup (Next.js)
- Server: `createClient(url, serviceRoleKey)` for API routes
- Client: `createClient(url, anonKey)` for browser with Realtime
